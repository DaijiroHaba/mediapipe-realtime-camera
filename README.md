# リアルタイム姿勢・通行観察 1.3

## 保存済み動画の解析 (2026-10-06)

公開URL https://daijirohaba.github.io/mediapipe-realtime-camera/ は変更していません。「映像入力」の「入力方法」で保存済み動画を選び、ファイルとモードを指定して「動画解析を開始」を押してください。姿勢、人流、併用の全3モードで利用できます。Chrome/EdgeでMP4/WebMを推奨し、MOV/AVI/M4Vはコーデックによって非対応です。復号できない場合はエラーを表示します。カメラ許可は不要です。

推定頻度をsample fpsとして使用し、最大3,000フレームを順に解析します。進捗を表示。通過・3秒以上の立ち止まりは元動画のサンプル時刻で判定し、処理にかかった時間は使用しません。各フレームの要求時刻・復号mediaTime・時刻取得状態は要約JSONのframe_timingに保存します。2 fps以上を使用し、欠測・低い元動画fps・ID切れによる計数の限界を確認してください。動画内のタイムスタンプは録画の実時刻や露光時刻を保証しません。

停止・タブ非表示で解析を中止できます。完了または上限停止後は最後の骨格/人物枠を表示し、要約JSON・イベントCSV・座標CSVをダウンロードできます。座標CSVは開始前に「座標を記録」をONにした姿勢/併用で生成し、人流のみは人物枠とイベントを扱います。ログ上限は従来どおりです。動画の再録画は行わず、動画入力中の録画ボタンは無効です。映像・座標をアップロードする機能はありません。

HTTPSの公開URLから開き、各自のPCにつないだカメラで使用するMediaPipeアプリです。配布者のPCの起動は不要です。利用者にNode.js、Python、インストール作業は不要です。公開前のファイルを直接ダブルクリックしてもカメラ解析は動作しません。公開方法は `PUBLISH_GUIDE.md`。

## カメラと全身表示

ChromeまたはEdgeで公開URLを開き、カメラを接続して「カメラを開始」を押し、ブラウザの許可に応答します。別のカメラを使う場合は停止し、一覧を更新して入力デバイスを選びます。

姿勢ランドマークでは最大1・2・4人を選択できます。2人を映す場合はカメラを停止し、2人以上を選択して開始してください。開始後は設定を固定するため人数欄は無効になります。骨格が1人だけ検出された場合に肘・膝の2D推定角度を表示します。まっすぐな内角は約180度です。頭と両足が画面に入り、全身の姿勢点が十分に見える位置で使います。脚が見えない場合は部分検出となり、見えない脚を描き足しません。枠は姿勢点を囲む人物枠で、頭頂付近の余白は目安です。顔認識枠ではありません。

人流・関心観察では独立した人物検出モデルで人物枠を推定し、最大20人を設定できます。骨格は計算しません。姿勢 ＋ 人流・関心観察では人物枠20人と骨格4人までを別々に設定できます。枠と骨格を重なりで対応させるため、枠全員に骨格が付くとは限りません。これらの上限は本アプリの設定で、必ず検出できる人数を意味しません。負荷・遮蔽・小さな人物によって検出漏れが生じます。

A/Bは通過線の両側です。元の映像で縦線の左がA、右がB、横線では上がA、下がBです。左右反転表示中は画面の左右も反転し、凡例に画面上の位置を表示します。人流の計数には人物枠の中心を使用します。姿勢のみのモードは人流・関心候補を計数しません。

通過はイベント回数で、ユニークな来訪者数ではありません。一時IDは個人識別ではなく、遮蔽・すれ違いで変わり得ます。角度・計数は医学的診断や妥当性検証済みの測定ではありません。

## 3秒以上の関心候補

人流または併用モードで、対象範囲内の人物枠中心が許容移動範囲に連続3秒以上とどまった場合に「関心候補」を1人相当として加算します。閾値は3〜60秒、対象範囲は映像全体または中央50%（左右幅）を選択できます。範囲から出る、中心が移動する、検出が欠ける場合は連続時間をリセットします。

同じ一時IDは1セッションに1回だけ関心候補人数に加算します。再び立ち止まると立ち止まりイベント回数のみ増えます。見失ってIDが変わった場合は同じ人が再加算され得ます。対象範囲に入った一時ID数が分母、3秒以上立ち止まった一時ID数が分子です。「関心候補率」はその割合を%で表示します。対象が0件のときは未定義として `--` / JSON `null` を出力します。

これは本アプリ・表示画面への関心度そのものではありません。注視や顔の向きは判定せず、待ち合わせ・行列等も候補になります。研究上の「関心」として採用する前に、同意・設置条件・対象範囲・観察による妥当性確認を行ってください。カメラは固定してください。

要約JSONに候補人数・分母・候補率・閾値・対象範囲・許容移動・限界を出力し、イベントCSVに初回関心候補と連続立ち止まり秒数を記録します。人流だけのモードはランドマーク座標CSVを作成しません。

## 全画面

映像上部の全画面アイコンで切り替えます。同じアイコンまたはEscで戻ります。全画面中もカメラ開始・停止、録画・保存、赤い録画OFF表示、通過・関心候補数を表示します。録画ファイルは元のカメラ解像度で、全画面用の表示倍率は録画解像度を変えません。

## 録画・保存

- 初期状態は録画OFFです。画面上部の赤い「録画していません」で確認できます。
- カメラの映像が出た後、動画アイコンの「録画を開始」を押した場合だけ映像を記録します。上部が録画中・経過時間に変わり、映像にもRECが付きます。
- 停止アイコンの「録画を停止」後、保存アイコンの「動画を保存」でランドマーク付きWebMを保存します。背景と顔も含み、音声は含みません。
- 録画は1回3分または約64 MBで自動停止します。カメラ停止・タブ非表示でも録画を停止します。自動再開はしません。
- 最後の録画をブラウザメモリに保持します。ブラウザを閉じる前に保存してください。未保存の前回録画を置き換えるときは確認します。
- WebMはブラウザの標準録画APIで作る形式です。MP4変換は実装していません。エラー時に保存できる断片は `_partial.webm` となります。
- 座標CSV・イベントCSV・要約JSONも端末へ保存できます。座標記録は録画と別設定で、開始前に選びます。CSVは日本語・UTF-8 BOM付きです。

映像・座標をサーバーに送信する機能はありません。サイト配信側には通常のアクセスログが残り得ます。保存先がOneDrive等なら保存後にそのサービスの同期が行われます。「録画していません」はこのアプリの状態であり、他アプリやOSの録画状態を判断する表示ではありません。

## 性能・配布

処理速度は利用者のPC、照明、人数、カメラの画角に依存します。遠い人や重なった人は見失うことがあります。研究・施設で使う場合は、利用条件とデータの扱いを確認してから使用してください。

モデル、MediaPipe/WASM、Lucideアイコンは同梱しています。公開後のアプリ実行中に外部CDNを読み込む必要はありません。配布物のライセンスは `vendor/LICENSE` と `vendor/icons/LICENSE`、由来とハッシュは `vendor/PROVENANCE.json` と `models/README_MODEL.txt` を参照してください。

## 姿勢の気づきモード（2026-10-06）

姿勢ランドマーク／併用モードの「表示」で「姿勢の気づき」を選択できます。人物枠の上に、上体の画面左右傾き、頭の画面左右傾き、肩の高さの差をアイコンと文章で最大2項目表示します。基本表示が初期値で、稼働中も切り替えられます。

正面を向き、顔・肩・腰が見える位置で、ゆっくり姿勢を変えて試してください。欠測、撮影方向の不足、動作、人物の重なり等では所見を保留します。画面上の位置関係を表す学習展示であり、測定妥当性と興味・学習効果は未検証です。詳しい定義、実装用閾値、限界は [POSTURE_AWARENESS.md](POSTURE_AWARENESS.md) を参照してください。

旧表示の場合は Ctrl＋F5 で再読み込みしてください。
